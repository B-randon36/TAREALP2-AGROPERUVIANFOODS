# TAREALP2-AGROPERUVIANFOODS

Proyecto integral para el curso de Lenguaje de Programación 2 (LP2) - AgroPeruvianFoods / BomERP.

## Estructura del Proyecto

El repositorio contiene tanto el backend como el frontend del sistema:

- **[`bomerp-backend/`](./bomerp-backend/)**: Backend desarrollado con Spring Boot 3 / 4, Spring Modulith y arquitectura monolítica modular.
- **[`bomerp-frontend/`](./bomerp-frontend/)**: Frontend desarrollado con Angular y diseño moderno para la gestión de catálogo y finanzas.

## Tecnologías

- **Backend**: Java 21, Spring Boot, Spring Data JPA, Oracle Database / H2, Spring Modulith, Maven Wrapper.
- **Frontend**: Angular, TypeScript, HTML5, CSS3.

## Ejecución

### Backend
```bash
cd bomerp-backend
.\mvnw.cmd spring-boot:run
```

### Frontend
```bash
cd bomerp-frontend
npm install
npm start
```
