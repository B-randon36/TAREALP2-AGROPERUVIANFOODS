🎓 Balotario y Respuestas Técnicas para Sustentación con el Profesor Rúbrica Oficial LP2

Estas son las 5 preguntas fundamentales de teoría y arquitectura que el docente suele evaluar durante la defensa técnica de los CRUDs y del monolito modular:

1. ¿Por qué usamos DTOs en lugar de exponer directamente las entidades JPA en los controladores? ▼
Respuesta para el docente:
  • Seguridad y Encapsulamiento: Evitamos el ataque de Mass Assignment y no exponemos campos internos sensibles o IDs autoincrementales que no corresponden al contrato público.
  • Prevención de Recursión Infinita: En relaciones bidireccionales de base de datos (@OneToMany y @ManyToOne), Jackson serializa cíclicamente provocando un desbordamiento de memoria (StackOverflowError). Los DTOs planos resuelven esto al desacoplar el contrato REST del modelo relacional.
  • Evolución del Contrato y Proyecciones: Permite utilizar consultas ligeras como SELECT new RendicionResumenDto(...), trayendo de la BD únicamente los campos indispensables sin saturar memoria ni disparar consultas lentas (evita el problema N+1 queries).
2. ¿Cómo garantiza @Transactional la atomicidad en la operación Cabecera-Detalle? ▼
Respuesta para el docente:

@Transactional enmarca todas las operaciones de la función dentro de una única transacción ACID a nivel de base de datos.

Al registrar una Rendición, ocurren tres operaciones: 1. Descuento del saldo en la Caja Chica. 2. Inserción de la cabecera en RENDICIONES_CAJA_CHICA. 3. Inserción en lote de los detalles en DETALLES_RENDICION_CAJA_CHICA.

Si se viola la regla RN-FIN-01 (monto total > saldo disponible), se lanza una SolvenciaInsuficienteException. Spring intercepta la excepción no verificada (Runtime) mediante AOP y emite automáticamente una orden de ROLLBACK al motor de base de datos, garantizando que o se guardan todos los registros o no se guarda ninguno, manteniendo el saldo y las tablas 100% íntegros.

3. ¿Por qué es fundamental que un reporte financiero retorne 0 o 0.00 en vez de null? ▼
Respuesta para el docente:

En el dominio contable y financiero de Agro Peruvian Foods, no tener movimientos en una caja o periodo significa cero transacciones (S/ 0.00), nunca un valor indeterminado o nulo.

Técnicamente, si SQL retornara null en funciones de agregación (como SUM o AVG sobre tablas vacías), el cliente frontend o servicios downstream lanzarían errores NullPointerException o mostrarían interfaces rotas con valores "NaN".

Para blindar esto, en el repositorio JPA usamos COALESCE(SUM(r.montoTotal), 0), garantizando que la API siempre responda con números reales estructurados.

4. ¿Qué es CORS y en qué capa del sistema se ejecuta la restricción? ▼
Respuesta para el docente:

CORS (Cross-Origin Resource Sharing) es una política de seguridad ejecutada exclusivamente por los Navegadores Web (no por Postman, cURL ni por el servidor backend).

Bajo la regla Same-Origin Policy, un script ejecutándose en un origen (por ejemplo http://localhost:5173 o un archivo local) tiene prohibido leer datos de otro origen (como http://localhost:8080).

En nuestro proyecto configuramos WebConfig.java implementando WebMvcConfigurer con cabeceras allowedOriginPatterns("*"), métodos GET, POST, PUT, DELETE, OPTIONS, PATCH y allowCredentials(true), permitiendo que cualquier frontend autorizado consuma la API con pre-vuelos OPTIONS exitosos.

5. ¿Cómo ayuda Spring Modulith a mantener los límites en este monolito modular? ▼
Respuesta para el docente:

Spring Modulith divide el backend en módulos de dominio de primer nivel: finanzas, catalogo, ventas y compras.

Aplica encapsulamiento estricto: ninguna clase o repositorio interno de un módulo puede ser importado o inyectado directamente por otro módulo. La única vía permitida es a través de puertos públicos declarados con @NamedInterface("api") en el package-info.java del módulo exportador.

Además, la prueba automática ModularityTests.java ejecuta ArchUnit en tiempo de compilación para verificar que no existan acoplamientos prohibidos ni ciclos de dependencias, garantizando la arquitectura limpia de microservicios con la simplicidad de un único monolito desplegable.
