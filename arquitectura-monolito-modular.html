COMPONENTE ARQUITECTÓNICO

TransaccionFinancieraController

[S] Single Responsibility [D] Dependency Inversion

Función en la Arquitectura:

Punto de entrada REST para el recurso de transacciones financieras y el reporte de Flujo de Caja.

Ubicación en el Monolito:

pe.edu.upeu.bomerp.finanzas.controller.TransaccionFinancieraController

Código Representativo:

@GetMapping("/resumen-flujo-caja") public ResponseEntity<FlujoCajaResumenResponse> obtenerResumenFlujoCaja() { return ResponseEntity.ok(finanzasService.obtenerResumenFlujoCaja()); }
💡 Principio SOLID Destacado:

Single Responsibility (SRP): No realiza sumas, agrupaciones SQL ni persistencia. Solo atiende solicitudes HTTP y mapea la respuesta con códigos de estado limpios.
